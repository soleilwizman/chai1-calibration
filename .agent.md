# Chai-1 calibration workspace guidance

## Project purpose
This repository supports calibration analysis for Chai-1 protein structure predictions using RCSB-derived candidate targets and covariate metadata.

## Working conventions
- Work from the repository root unless a task explicitly requires otherwise.
- Prefer small, reproducible Python scripts over one-off notebook edits when the same workflow can be scripted.
- Preserve the existing data layout under data/targets/ and avoid overwriting raw inputs unless the task explicitly asks for it.
- Keep outputs deterministic and easy to inspect as JSON, CSV, or text artifacts.
- When adding new analysis code, prefer clear CLI entry points and readable functions.

## Python environment
- The repository includes a local virtual environment at .venv/ and a setup helper at scripts/setup_venv.sh.
- Preferred setup:
  - `bash scripts/setup_venv.sh`
  - or `source .venv/bin/activate`
- If a conda environment is already in use, it is also acceptable, but keep the workflow explicit and reproducible.

## Existing scripts and data
- `scripts/extract_searchable_attrs.py` reads schema.json and writes searchable RCSB attribute names to `scripts/searchable_attrs.txt`.
- `scripts/extract_candidate_covariates.py` fetches candidate metadata from RCSB and writes covariates to `data/targets/candidates_covariates.json`.
- `data/targets/candidates_raw.json` is the canonical source of candidate identifiers.
- `schema.json` is the authoritative schema for searchable attributes.

## Repository-specific notes
- The baseline candidate pool is defined by the filtering logic described in README.md.
- Keep the apo/holo distinction and other covariates available rather than collapsing them away unless a task specifically requires filtering.
- Be cautious with network-dependent fetches; the existing script uses local caching under `data/targets/rcsb_cache/`.

## Preferred workflow for new work
1. Read the relevant README section and nearby scripts before changing behavior.
2. Make the smallest change that addresses the task.
3. Verify the result with the relevant script or command rather than assuming it works.
4. If a change affects data generation, preserve the source artifact and write a new derived artifact.

## Useful commands
- `python scripts/extract_searchable_attrs.py`
- `python scripts/extract_candidate_covariates.py --max 10`
- `source .venv/bin/activate`
